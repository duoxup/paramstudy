## C1 — P0：运行时 bug

### Fix H1 — secondary contour 在 z/z2 NaN 模式不同时形状不匹配

**根因**：`src/paramstudy/render/matplotlib_axes.py:464-491` `_draw_secondary_grid_contour` 接收主路径的 `xs, ys`（由 `subset = df[[x,y,z]].dropna()` 算出），但函数内用全 df 重新构造 `z2_grid`。当 z 与 z2 的 dropna 后唯一坐标集不同 → shape 不齐或抛 TypeError。

**补丁草稿**（matplotlib_axes.py）：

```python
def _draw_secondary_grid_contour(
    ax: plt.Axes,
    df: pd.DataFrame,
    spec: PlotSpec,
    options: AxesOptions,
    x_scale: UnitScale | None,
    y_scale: UnitScale | None,
) -> None:
    z2_col = options.secondary_contour.column
    if z2_col is None or z2_col not in df.columns:
        return
    subset2 = df[[spec.inputs.primary, spec.inputs.secondary, z2_col]].dropna()
    if subset2.empty:
        return
    xs2, ys2, z2_grid = _prepare_heatmap_grid(
        subset2, spec.inputs.primary, spec.inputs.secondary, z2_col, options
    )
    if xs2.size == 0 or ys2.size == 0:
        return
    x_mult = x_scale.multiplier if x_scale is not None else 1.0
    y_mult = y_scale.multiplier if y_scale is not None else 1.0
    cs = ax.contour(
        xs2.astype(float) * x_mult,
        ys2.astype(float) * y_mult,
        z2_grid,
        levels=options.secondary_contour.levels,
        colors=options.secondary_contour.color,
        linewidths=options.secondary_contour.linewidths,
    )
    if options.secondary_contour.labels:
        _apply_secondary_contour_labels(ax, cs, options.secondary_contour)
```

调用点（`draw_heatmap_axes:174`、`draw_contour_axes:229`）相应去掉 `xs, ys` 参数：

```python
_draw_secondary_grid_contour(ax, df, spec, options, x_scale, y_scale)
```

### Fix H2 — shared colorbar 在 log z 下丢 LogNorm

**根因**：`src/paramstudy/render/matplotlib_figure.py:441-452` `_shared_colorbar_mappable` 无条件用 `Normalize` 构造合并 mappable。

**补丁草稿**（matplotlib_figure.py，文件顶部 imports 加入 `LogNorm`）：

```python
from matplotlib.colors import LogNorm, Normalize

def _shared_colorbar_mappable(items: list[tuple[Any, plt.Axes, AxesSlot]]) -> Any:
    mappable = items[0][0]
    clim = [item[0].get_clim() for item in items if isinstance(item[0], ScalarMappable)]
    if not clim:
        return mappable
    vmins = [pair[0] for pair in clim if pair[0] is not None]
    vmaxs = [pair[1] for pair in clim if pair[1] is not None]
    if not vmins or not vmaxs:
        return mappable
    vmin, vmax = min(vmins), max(vmaxs)
    source_norm = getattr(mappable, "norm", None)
    if isinstance(source_norm, LogNorm):
        norm = LogNorm(vmin=vmin, vmax=vmax)
    else:
        norm = Normalize(vmin=vmin, vmax=vmax)
    cmap = getattr(mappable, "cmap", None)
    return ScalarMappable(norm=norm, cmap=cmap)
```

## C2 — P1-a：CSV 单位静默兜底

### Fix M2 + A-2.2 — `_clean_csv_unit` warning + CompoundUnit 自定义 separator

**根因**：
- `src/paramstudy/metadata.py:261-268` `_clean_csv_unit` 在 `parse_unit` 失败时静默退回 `Unitless`。
- `src/paramstudy/unit.py:197-240` `parse_unit` 仅识别空格作分隔。`CompoundUnit(separator=".")` 渲染为 `"m.s"`，往返后变成 `Unitless`。

**补丁草稿**：

(a) metadata.py — 加 warning：

```python
import warnings

def _clean_csv_unit(value: str) -> UnitLike | None:
    text = value.strip()
    if not text:
        return None
    try:
        return parse_unit(text)
    except ValueError:
        warnings.warn(
            f"Unrecognized unit string {value!r} in CSV; falling back to Unitless. "
            "Use JSON serialization for full fidelity.",
            stacklevel=3,
        )
        return Unitless(label=text)
```

(b) metadata.py — `ColumnMeta.to_csv_row` 渲染时把 CompoundUnit 的 separator 强制规范化为空格，避免无法 round-trip 的 separator 进入 CSV：

```python
def to_csv_row(self) -> dict[str, str]:
    return {
        "label": self.label or "",
        "symbol": self.symbol or "",
        "unit": _render_csv_unit(self.unit),
        "preferred_unit": _render_csv_unit(self.preferred_unit),
    }

def _render_csv_unit(unit: UnitLike | None) -> str:
    if unit is None:
        return ""
    if isinstance(unit, CompoundUnit) and unit.separator != " ":
        warnings.warn(
            f"CompoundUnit.separator={unit.separator!r} is not CSV-roundtrippable; "
            "normalizing to space. Use JSON serialization for full fidelity.",
            stacklevel=3,
        )
        return CompoundUnit(unit.units, separator=" ").render()
    return unit.render()
```

### Fix M4 — `_resolve_slot_color_settings` EACH + user_override 不要全局化

**根因**：`src/paramstudy/render/matplotlib_figure.py:386-403`。当 mode 是 EACH 且 user 设置了 vmin 或 vmax，整个分支跳到 "global limits + global scale"。

**补丁草稿**（matplotlib_figure.py）：

```python
def _resolve_slot_color_settings(...) -> dict[int, _ColorSlotSettings]:
    column = spec.responses.color or spec.responses.primary
    if column is None or column not in df or not pd.api.types.is_numeric_dtype(df[column]):
        return {}

    mode = figure_options.colorbar.mode
    user_override = (
        axes_options.color.vmin is not None or axes_options.color.vmax is not None
    )

    result: dict[int, _ColorSlotSettings] = {}

    if mode in (ColorbarMode.NONE, ColorbarMode.EACH):
        # per-slot scale; per-slot auto-limits with optional user override on either side.
        for slot in plan.slots:
            if not slot.has_data or slot.is_unused:
                continue
            subset = _subset_for_slot(df, spec, slot)
            limits, scale = _column_limits_and_scale(subset, column, meta, axes_options)
            result[slot.index] = _ColorSlotSettings(
                limits=limits if user_override else None,
                scale=scale,
            )
        return result

    if mode is ColorbarMode.FIGURE:
        limits, scale = _column_limits_and_scale(df, column, meta, axes_options)
        return {slot.index: _ColorSlotSettings(limits, scale) for slot in plan.slots}

    # ROW / COL：保持现状
    group_attr = "layout_row" if mode is ColorbarMode.ROW else "layout_col"
    ...
```

注意 `_column_limits_and_scale` 已经处理了 user vmin/vmax 覆盖逻辑，所以这里仅需把数据源从全 df 换成 per-slot subset。

### Fix A-Design #3 — 合并两份 `_resolve_column_scale`

**根因**：`src/paramstudy/render/matplotlib_axes.py:348-363` 和 `src/paramstudy/render/matplotlib_figure.py:343-357` 是同一逻辑两份实现，只是参数形态不同（一个收 registry、一个收 ColumnMeta）。

```python
# render/_util.py
def resolve_column_scale(
    df: pd.DataFrame,
    column: str,
    column_meta: ColumnMeta,
    options: AxesOptions,
) -> UnitScale | None:
    if column_meta.unit is None or not pd.api.types.is_numeric_dtype(df[column]):
        return None
    return resolve_unit_scale(
        df[column].dropna().to_numpy(),
        column_meta.unit,
        preferred_unit=column_meta.preferred_unit,
        autoscale=options.units.autoscale,
        use_preferred=options.units.use_preferred,
    )
```
